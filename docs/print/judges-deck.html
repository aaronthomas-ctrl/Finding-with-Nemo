Every write is an approval card. Web text is fenced as untrusted, and write tools are blocked after a flagged result.

8

What we learned, and what is next

Honest limits

  • Speech recognition uses the browser; Token Factory has no audio endpoint.
  • Embeddings are Qwen: no Nemotron embedding model was available.
  • Multi-step agent answers take 20 to 60 seconds.
  • Malayalam and Urdu translation were unreliable; Arabic and Hindi were fine.

Next

  • Nemotron speech recognition for voice notes.
  • A Nemotron safety model for screening web text.
  • Scheduled watchers as Nebius Jobs.
  • Team assignment of leads.

Lesson: evidence beats confidence. A model sentence only counts when code can find its quote on the page.
